Expand description

A cell effect that modifies the cells covered by a Shadow.

Custom effects must keep the same auto-trait guarantees as the widgets that store them: Send, Sync, UnwindSafe, and RefUnwindSafe. This preserves the thread-safety and panic-safety behavior of widgets that contain a Block.

See Shadow::custom for how to create a shadow from a custom effect.
